// why it is a different security problem
Concentration

It reaches every environment

Compromise the pipeline and you inherit everything it can deploy to. The blast radius is the estate, not the repository.

Execution

It runs code from strangers

A fork pull request, a new transitive dependency, a build plugin. All executing with the runner's identity and its cloud access.

// what actually causes the incidents

The recurring failures

  • Long-lived cloud access keys stored as CI secrets, never rotated.
  • Fork pull requests running with access to real secrets.
  • Third-party actions pinned to a mutable tag, not a commit SHA.
  • Self-hosted runners reused across jobs, teams and environments.
  • Secrets echoed into build logs, retained for months.
  • One deploy identity shared between staging and production.
