// NETWORK & DNS
A server calling a model API, or an out-of-band domain
The agent has to reach its brain. Calls to model APIs, and lookups of interactsh or dnslog callbacks, survive a change of tool.

// CLOUD
Credentials used at machine speed
Many identities checked from one address, bulk data reads, instance role keys used from outside. Same pattern in AWS, Azure, M365 and Okta.
Respond before it moves wide
Isolate and kill the runtime
Remove the container, not just the process, and cut the host's egress.
Cut the two lifelines
Block the model API and the proxy pool. No brain, no plan. No proxies, no cover.

Capture the agent's own logs
